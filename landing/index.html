how the sentence is cut

What happens to your sentence

Most dictation tools regenerate your text. Voicy cuts two spans out of it.

message Pulkit that I'll be late, leaving now
verb, dropped recipient, matched against your contacts connector, dropped body, sliced by character offset, sent as-is

The body is characters, copied by offset. There is no rewriting step to fail, so Hinglish survives too.

Dictation solved the wrong half

Getting your words down is a solved problem. None of those tools know who you are talking to, so you still CmdTab into WhatsApp and scroll past two hundred chats to find one person. Typing was never the slow part.

AaravArav our ab our ad

We tried the three documented fixes

  1. Contextual strings

    Contact names fed to the recognizer as hints. Byte-identical output.

  2. The en_IN locale

    Byte-identical output, and about 1.5× slower.

  3. A custom language model

    Byte-identical again, at 1576 ms worst case.

So names are fixed after recognition instead. Correct one once and it resolves forever.

Three things it will not do

Rewrite you

The body is a slice, not a generation. A language model exists in the repo and is deliberately not wired in.

Guess a recipient

Two Rahuls and it asks. It never picks the likelier one, because a sent WhatsApp message cannot be recalled.

Touch a WhatsApp API

A whatsapp://send link, the same one behind every “chat on WhatsApp” button on the web. Nothing to ban.

What leaves your Mac

Nothing.

  • Voice transcribed on-device, no server and no API key.
  • Messages never stored and never logged.
  • Contacts read into memory, never uploaded.
  • Microphone open only while you hold the key.
  • Kill switch a blocklist that refuses everything if it cannot be read.

Voicy asks for Microphone and Contacts. Input Monitoring and Accessibility are optional and off; everything on this page works without them.

half done, not wired in

Voice notes: decoded, not yet readable

Decoding real WhatsApp voice notes works, proven on real files. Transcribing them does not: the ones we sampled are Hindi and Punjabi, and the English model turns those into confident nonsense. It needs language selection before it ships.

Will this get my WhatsApp banned?

No API is involved, so there is nothing to detect as automation. From WhatsApp's side, a person opened the app and pressed a key.

Does my audio leave my Mac?

No. On-device Speech framework, no server and no upload step in the code. The repo is open, so you can check.

What is not finished?

Auto-send, the ambiguous-contact picker, the edit shortcut and the hold-to-talk key have code and tests but have never been run end to end by a human. Voice notes decode but are not wired in. The pitch page lists all of it.

One key held down, and the message is sitting in the right chat.
