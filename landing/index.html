how the sentence is cut

What happens to your sentence

Voicy cuts the recipient and message body from what you said. Cleanup only removes disfluencies.

message Pulkit that I'll be late, leaving now
verb, dropped recipient, matched against your contacts connector, dropped body, sliced by character offset, never regenerated

The body is copied by character offset. There is no rewrite step.

Find the person while you speak

Dictation puts words in a box. It does not choose the WhatsApp chat. Voicy takes a name from the sentence, matches it to Contacts, and opens that chat.

Three fixes changed nothing

  1. Contextual strings

    Contact names fed to the recognizer as hints. Byte-identical output.

  2. The en_IN locale

    Byte-identical output, and about 1.5× slower.

  3. A custom language model

    Byte-identical again, at 1576 ms worst case.

So names are fixed after recognition instead. Correct one once and it resolves forever.

Use a WhatsApp deep link

Voicy opens WhatsApp with a whatsapp://send link. It makes no API calls.

Your audio stays on this Mac

Nothing leaves.

  • Audio is transcribed on-device.
  • Network calls: zero.
  • Messages are never stored or logged.
  • Contacts are read into memory, never uploaded.
  • Microphone opens only while you hold the key.

Voicy asks for Microphone and Contacts. Input Monitoring and Accessibility are optional and off by default.

half done, not wired in

Received voice notes still need language support

Voicy can decode real WhatsApp voice-note files. Transcription is not ready: the sampled files were Hindi and Punjabi, while the current recognizer runs en_US.

“WhatsApp's voice note transcription on desktop is either missing entirely or very inaccurate for me. It skips words, struggles with accents, and sometimes just isn't available at all, so I built a local alternative.”

jpxoi, Threads

Will this get my WhatsApp banned?

Voicy opens WhatsApp with a deep link. It does not use a WhatsApp API.

Does my audio leave my Mac?

No. Speech runs on-device, and Voicy makes zero network calls.

What is not finished?

Auto-send is untested end to end, and live sends are currently restricted to one allowlisted number. Voice notes decode but are not wired into the UI. The pitch page lists the limits.
